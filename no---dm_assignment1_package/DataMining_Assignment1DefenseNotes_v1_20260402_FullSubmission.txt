Data Mining Assignment 1 - Defense Notes

1. Sequence
I followed the assignment in this order: outlier detection, correlation filtering, entropy-based discretization, class-stratified train/test split, Apriori frequent itemset mining, association rule generation, balance check, prediction, and final metrics.

2. Outliers
I used population standard deviation because the assignment treats the 414 records as the full population. I marked any value outside AVG ± 2*STD as an outlier and removed any record containing at least one outlier. That removed 105 records and left 309 cleaned records.

3. Correlation
I used Pearson correlation because the assignment says Pierce correlation, but the study guide gives the Pearson formula. I printed the chosen threshold, 0.70, next to the correlation matrix. No pair exceeded the threshold, so no attribute was removed as redundant.

4. Discretization
For each remaining independent attribute, I sorted the values in descending order, computed adjacent differences, selected the three largest differences, built Diff_Union, and tested only those candidate thresholds with information gain. I kept the threshold with maximum information gain for each attribute.

5. Seed and split
I used random seed 100 so the class-stratified random draw is reproducible. The seed does not freeze one row. It freezes the entire random selection process. I rounded the 10% class counts up so Econ-TEST would contain at least 10% of both treat groups. That produced 18 records with treat = 1 and 14 records with treat = 0 in Econ-TEST.

6. Minimum support count
I tested support counts across the verified pipeline. Support 20 looked attractive because it was stricter, but the full run showed that it eliminated all final Format-1 rules with a treat conclusion. Support 17 was the strongest verified cutoff that still preserved treat-prediction rules for Part 3, so the final run uses minimum support count = 17.

7. Balance check
On Econ-TRAIN, treat = 1 had 154 records and treat = 0 had 123. IR = |154 - 123| / 277 = 0.1119, which is below 0.4. So the dataset was treated as balanced and I used standard confidence, not Kulczynski confidence.

8. Table A and rule translation
Table A maps each attribute and discrete value to an I-label and a range. That is what makes it possible to translate mined I-label rules back into Format-1 and Format-2.

9. Prediction assumption
All surviving Format-1-Rules concluded treat = 1. To assign exactly one binary prediction per Econ-TEST record, I documented unmatched rows and defaulted them to treat = 0. That assumption is stated clearly in the report.

10. Metrics
The final matrix was:
TP = 4
FN = 14
FP = 0
TN = 14

Accuracy = (4 + 14) / 32 = 0.5625
Recall = 4 / 18 = 0.2222
Precision = 4 / 4 = 1.0000

The result means the positive predictions were perfectly precise, but recall was low because only 4 of the 18 positive test rows matched the final rule set.
