# Assignment 2 — From-Scratch ID3 and Naive Bayes

This independent graduate Data Mining project implements two classifiers from scratch for DFCA product-order data. The user selects either ID3 or Naive Bayes, and the program produces calculation-level evidence, predictions, metrics, reports, and defense notes.

## Assignment Context

The official deliverable was a live, one-to-one Zoom execution and defense. The instructor evaluated whether each program ran successfully; a conventional prewritten final report was not the primary deliverable.

The instructor also explicitly required use of the test set during ID3 post-pruning. That classroom requirement is preserved here and should not be mistaken for an undocumented production-modeling choice.

## Implemented Classifiers

### ID3

- calculates entropy, weighted entropy, and information gain;
- selects the highest-gain attribute at each decision node;
- applies user-selected pre-pruning threshold `T1`;
- applies user-selected post-pruning parameter `g`;
- extracts readable IF-THEN rules; and
- evaluates multiclass predictions before and after post-pruning.

### Naive Bayes

- calculates class priors and categorical conditional probabilities;
- identifies continuous attributes specified by the assignment;
- calculates Gaussian probability components;
- detects zero-frequency cases and applies Laplace smoothing when needed; and
- produces class scores, predictions, a confusion matrix, and per-class metrics.

## Run the Program

```bash
cd assignment2_package
python -m venv .venv
```

Activate the environment, then run:

```bash
python -m pip install -r requirements.txt
python DataMining_Assignment2Pipeline_v1_20260506_FullSubmission.py
```

The program will ask you to:

1. choose `ID3` or `Bayes`;
2. enter `T1` and `g` if ID3 is selected; and
3. observe the calculation and file-generation progress.

Python 3.10 or newer is required. The program validates the runtime, dependencies, and four required CSV files before processing.

## Skills Demonstrated

- decision-tree construction without a classifier library
- entropy and information-gain calculations
- pre-pruning and post-pruning logic
- IF-THEN rule extraction
- Naive Bayes probability modeling
- Gaussian probability density calculations
- Laplace smoothing

## Academic Scope

The classifiers are educational implementations, not production systems. The dataset, thresholds, pruning rule, and live-execution format follow the professor's assignment. In particular, the professor-required use of test data during post-pruning would normally require a separate validation strategy in production work.
